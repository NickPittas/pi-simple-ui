# Pi Desktop v0.1.5

Cumulative notes for v0.1.1 to v0.1.5. Full history in [CHANGELOG.md](../../CHANGELOG.md).

## Highlights
- Attachments: pick, drag-drop or paste files and images into the composer; their paths are inserted into the message.
- Slash-command results show inline in the conversation.
- Model picker: fuzzy search, scoped models by default, "Show all models" toggle.
- Models page: edit scoped models (`enabledModels`) and restart Pi to apply.
- Regression suite: `npm test`.

## Downloads and requirements
- `Pi-Desktop-0.1.5-x86_64.AppImage`, `Pi-Desktop-0.1.5-amd64.deb`, `SHA256SUMS`.
- Linux x86-64 and a separately installed, configured Pi CLI.

## Notes
- Inline command results are attributed by timing, not by command id, and are not persisted.
- Saving scoped models rewrites `settings.json` with 2-space indentation; other keys are preserved, other formatting is not.
- Pi's own model cycling only picks up a changed scope after "Restart Pi to apply".
- No custom application icon; Linux builds use Electron's default.
