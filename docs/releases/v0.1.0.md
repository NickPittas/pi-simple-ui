# Pi Desktop v0.1.0

Initial Linux x86-64 packages for the graphical companion to native Pi.

## Highlights

- Dark conversation interface with differentiated message, thinking, and tool presentation.
- Native Pi RPC prompt/reply flow, model/thinking controls, and new-chat handling.
- Workspace selection, a separate workspace shell terminal, and native configuration/resource views.
- Pi remains authoritative for execution and authentication; Herdr remains external.

## Downloads and requirements

- `Pi-Desktop-0.1.0-x86_64.AppImage`
- `Pi-Desktop-0.1.0-amd64.deb`

Requires Linux x86-64 and a separately installed, configured Pi CLI. Executable discovery uses `$PI_CODING_AGENT_DIR/bin/pi`, otherwise `~/.pi/agent/bin/pi`, then `pi` on `PATH` if the selected managed executable is unavailable. A Nerd Font is recommended for terminal-origin glyphs. User credentials and configuration are not included.

## Notes

- Native `node-pty` is rebuilt for Electron and unpacked from the application archive.
- There is no custom application icon in this release.
- Custom terminal UI/extension compatibility depends on the native host's capabilities; universal support is not claimed.
- Build/typecheck and artifact inspection are not substitutes for full feature confirmation. No regression test suites were created or run for this packaging pass.
